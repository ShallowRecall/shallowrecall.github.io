ABOUT RECALL API · ONE ENDPOINT

关于 Recall 让连接更简单。

Recall API 是一个由 New API 驱动的模型聚合入口。用一套兼容 OpenAI 的接口连接不同供应商，在同一个控制台中管理令牌、余额与用量。

OpenAI兼容协议
统一模型入口
透明计费目录

BUILT FOR BUILDERS

少改代码，多接模型。

保留熟悉的 OpenAI 调用方式，把供应商差异留在网关之后。模型广场负责展示，控制台负责实际接入与管理。

⌘

统一接口

沿用 OpenAI 兼容协议与常见 SDK，通过同一个基础地址调用目录中的模型，减少为不同供应商重复适配的成本。

◫

透明目录

模型广场展示当前可用模型、供应商、端点与站内换算价格；最终扣费与分组倍率以 New API 控制台为准。

↗

集中管理

在控制台统一创建令牌、查看余额和调用记录，并根据业务需要切换模型，不必维护多套账号与配置。

一个入口，覆盖完整工作流。

从原型验证到线上应用，Recall API 将模型发现、密钥管理、请求转发与用量查看放在同一条路径里。你只需要选择模型、创建令牌，然后把请求发往统一接口。
