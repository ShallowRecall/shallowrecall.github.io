# Artalk emoticon packs

Local JSON packs used by the Artalk comment editor.

- `default.json`: ArtalkJS/Emoticons `grps/default.json`
- `huaji.json`: qwqcode/huaji
- `tusiji.json`, `tom_jerry.json`, `weibo.json`, `lengtu.json`: 2X-ercha/Twikoo-Magic

The Twikoo-Magic JSON files reference images hosted on Alibaba Cloud OSS.
