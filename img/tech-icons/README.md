# Tech icon sources

These marks are used only for the homepage technology wall.

- Brand marks: [Simple Icons](https://simpleicons.org/) (`spring`, `mysql`, `redis`, `docker`, `vmware`, `truenas`, `grafana`, `hexo`, `threedotjs`, `linux`, `vuedotjs`, `nginx`, `git`, `cloudflare`, `proxmox`, `homeassistant`, `qbittorrent`, `debian`, `uptimekuma`, `markdown`, `obsidian`).
- Java mark: [Devicon](https://devicon.dev/).
- OpenList, fnOS, Beszel, NetAlertX: official icons from their respective product websites.
- Homelab, NAS, J4125 and All-in-One use generic Font Awesome icons because they are categories, not brands.
